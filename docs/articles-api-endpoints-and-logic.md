## Ключевые принципы

1) **Все `/articles*` эндпойнты требуют авторизации** (проверка активной сессии).
2) **Статья принадлежит пространству** и наследует права доступа от него.
3) **Создание статей** доступно только владельцу пространства.
4) **Версионирование**: каждая статья имеет версии, каждая версия сохраняется полностью.
5) **Контент в Markdown**: поле `content` содержит Markdown-разметку.

---

## Термины
- **Article** — статья в пространстве.
- **Version** — версия статьи с полным контентом.
- **Space** — пространство, контейнер статей.

---

## Авторизация и проверка сессии
Все эндпойнты `/articles*` должны выполнять проверку "пользователь аутентифицирован" до бизнес-логики.

---

## Роли и доступы
- **Создание статьи**: только владелец пространства (`role = "owner"`).
- **Просмотр версий**: любой участник пространства (`role` не null).

---

## Версионирование статей
- Каждая статья имеет уникальный ID.
- Версии нумеруются последовательно (1, 2, 3...).
- При создании статьи автоматически создаётся версия 1.
- Каждая версия содержит: title, content (MD), author_id, created_at.

## Контракт эндпойнтов

### POST /spaces/{space_id}/articles
Создаёт новую статью в указанном пространстве.

**Тело запроса:**
```json
{
  "title": "string (1-255 chars, not empty)",
  "content": "string (MD format)"
}
```

**Успешный ответ (201):**
```json
{
  "id": "uuid"
}
```

**Ошибки:**
- 400 VALIDATION_ERROR: пустой title
- 401 SESSION_MISSING/SESSION_EXPIRED
- 403 FORBIDDEN: не владелец пространства
- 404 NOT_FOUND: пространство не найдено

### GET /articles/{article_id}/versions
Возвращает список всех версий статьи.

**Успешный ответ (200):**
```json
[
  {
    "id": "uuid",
    "article_id": "uuid",
    "version_number": 1,
    "title": "string",
    "content": "string (MD)",
    "author_id": 1,
    "created_at": "2026-01-01T12:00:00Z"
  }
]
```

**Ошибки:**
- 401 SESSION_MISSING/SESSION_EXPIRED
- 403 FORBIDDEN: нет доступа к пространству
- 404 NOT_FOUND: статья не найдена

### GET /articles/{article_id}
Возвращает последнюю версию статьи.

**Успешный ответ (200):**
```json
{
  "id": "uuid",
  "article_id": "uuid",
  "version_number": 1,
  "title": "string",
  "content": "string (MD)",
  "author_id": 1,
  "created_at": "2026-01-01T12:00:00Z"
}
```

**Ошибки:**
- 401 SESSION_MISSING/SESSION_EXPIRED
- 403 FORBIDDEN: нет доступа к пространству
- 404 NOT_FOUND: статья не найдена или нет версий

### GET /articles/{article_id}/{version_id}
Возвращает конкретную версию статьи по ID версии.

**Успешный ответ (200):**
```json
{
  "id": "uuid",
  "article_id": "uuid",
  "version_number": 1,
  "title": "string",
  "content": "string (MD)",
  "author_id": 1,
  "created_at": "2026-01-01T12:00:00Z"
}
```

**Ошибки:**
- 401 SESSION_MISSING/SESSION_EXPIRED
- 403 FORBIDDEN: нет доступа к пространству
- 404 NOT_FOUND: версия не найдена
- 400 VALIDATION_ERROR: версия не принадлежит указанной статье

### PATCH /articles/{article_id}
Обновляет статью, создавая новую версию. Только владелец пространства или суперадмин.

**Тело запроса:**
```json
{
  "title": "string (1-255 chars, not empty)",
  "content": "string (MD format)"
}
```

**Успешный ответ (200):**
```json
{
  "id": "uuid" // новая версия
}
```

**Ошибки:**
- 400 VALIDATION_ERROR: пустой title
- 401 SESSION_MISSING/SESSION_EXPIRED
- 403 FORBIDDEN: нет прав (не владелец/не админ)
- 404 NOT_FOUND: статья не найдена

### DELETE /articles/{article_id}
Мягкое удаление статьи. Устанавливает `deleted_at`. Только владелец пространства или суперадмин.

**Успешный ответ (204):**
нет тела

**Ошибки:**
- 401 SESSION_MISSING/SESSION_EXPIRED
- 403 FORBIDDEN: нет прав (не владелец/не админ)
- 404 NOT_FOUND: статья не найдена
